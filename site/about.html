About, limitations & disclaimer

A free hobby project that puts everyday spreadsheet chores in your browser.

What this is

Excel Tools by gumber.ai is a free set of 20 spreadsheet tools built as a hobby project. There is no company behind it, no paid plan, no ads and no account. It is completely free to use.

Privacy

All processing happens in your browser with JavaScript. Files you open are read into your device’s memory and never sent to a server. The page loads open-source libraries (SheetJS, JSZip, pdf.js, Tesseract.js) and fonts from public CDNs; your data is not sent with those requests. Your theme preference is saved in your browser’s local storage, and a file you drop on the home page is kept briefly in your browser’s own storage (IndexedDB) so it can open in the tool you pick — it is deleted as soon as that tool loads.

Limitations

Because everything runs in the browser, the tools are limited by your device’s memory and processing power:

  • Everything runs in your browser’s memory, so the practical file size depends on your device. As a rough guide: up to ~50 MB or ~500,000 rows works well on a modern laptop; phones and tablets handle much less.
  • Very large files can make the tab slow or crash. If that happens, split the file first or use a desktop computer.
  • Outputs keep values and formulas’ results but not formatting, charts, images, pivot tables or macros.
  • Password-protected workbooks can’t be opened.
  • PDF to Excel works on digital PDFs only; scanned pages need the Image to Excel (OCR) tool. OCR accuracy depends on image quality.
  • Fuzzy lookups compare every unmatched value against the lookup table, so very large tables (tens of thousands of rows on both sides) can take a while.
