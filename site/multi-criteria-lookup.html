Multi-Criteria Lookup

Match rows on two or more columns at once, e.g. Name + Date.

About Multi-Criteria Lookup

When one column isn’t unique, match on several together — like Customer + Month or SKU + Warehouse — and pull back the right values.

How to use Multi-Criteria Lookup

  1. Upload both tables.
  2. Add a criterion for each column pair that must match.
  3. Choose the return columns, run the lookup and download.

Limitations

  • Everything runs in your browser’s memory, so the practical file size depends on your device. As a rough guide: up to ~50 MB or ~500,000 rows works well on a modern laptop; phones and tablets handle much less.
  • Very large files can make the tab slow or crash. If that happens, split the file first or use a desktop computer.
  • Outputs keep values and formulas’ results but not formatting, charts, images, pivot tables or macros.

Frequently asked questions

How many criteria can I add?

As many as you need.

Do criteria need the same column names?

No, you pair any column in the main table with any column in the lookup table.

Can I combine this with fuzzy matching?

Yes, set the match type to fuzzy.
