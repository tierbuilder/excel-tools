JSON to Excel

Paste or upload JSON and get a clean spreadsheet. Nested objects are flattened into columns.

About JSON to Excel

Paste an API response or upload a .json file and get a tidy spreadsheet. Nested objects become dotted columns (address.city), simple arrays are joined, and an object of arrays becomes one sheet per key.

How to use JSON to Excel

  1. Paste JSON into the box or drop a .json file.
  2. Click “Convert to Excel”.
  3. Review the preview and download the .xlsx file.

Limitations

  • Everything runs in your browser’s memory, so the practical file size depends on your device. As a rough guide: up to ~50 MB or ~500,000 rows works well on a modern laptop; phones and tablets handle much less.
  • Very large files can make the tab slow or crash. If that happens, split the file first or use a desktop computer.
  • Outputs keep values and formulas’ results but not formatting, charts, images, pivot tables or macros.

Frequently asked questions

What JSON shapes are supported?

An array of objects, an array of arrays, a single object, or an object whose values are arrays (each becomes a sheet).

What happens to nested arrays?

Arrays of simple values are joined with commas; arrays of objects are kept as JSON text in the cell.

Is there a size limit?

Only your browser’s memory — see the limitations below.
