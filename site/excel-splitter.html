Excel Splitter

Split a workbook by sheet, by row count, into equal parts, or by the values in a column.

About Excel Splitter

Break a large spreadsheet into manageable pieces. Split every 1,000 rows for imports, into equal parts for teammates, by region or category, or save each sheet as its own file.

How to use Excel Splitter

  1. Drop the spreadsheet you want to split.
  2. Choose a split mode and set N or the column.
  3. Click “Split file”, then download a ZIP of files or one workbook with a tab per part.

Limitations

  • Everything runs in your browser’s memory, so the practical file size depends on your device. As a rough guide: up to ~50 MB or ~500,000 rows works well on a modern laptop; phones and tablets handle much less.
  • Very large files can make the tab slow or crash. If that happens, split the file first or use a desktop computer.
  • Outputs keep values and formulas’ results but not formatting, charts, images, pivot tables or macros.

Frequently asked questions

Is the header row kept in every part?

Yes, by default the header is repeated in each file.

Can I split by a column like “Country”?

Yes — choose “By unique values in a column” and every value gets its own file.

What output formats are available?

A ZIP of XLSX files, a ZIP of CSV files, or a single workbook with one tab per part.
