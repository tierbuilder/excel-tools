Compress Excel

Shrink bloated XLSX/XLS files by rewriting them with maximum compression.

About Compress Excel

Shrink bloated workbooks by rewriting the data with maximum compression. Best for data-heavy files that need to be emailed or uploaded.

How to use Compress Excel

  1. Add one or more workbooks.
  2. Click “Compress”.
  3. Compare sizes and download the smaller files.

Limitations

  • Everything runs in your browser’s memory, so the practical file size depends on your device. As a rough guide: up to ~50 MB or ~500,000 rows works well on a modern laptop; phones and tablets handle much less.
  • Very large files can make the tab slow or crash. If that happens, split the file first or use a desktop computer.
  • Outputs keep values and formulas’ results but not formatting, charts, images, pivot tables or macros.

See all limitations

Frequently asked questions

What is removed?

Formatting, charts, images and macros are dropped — values and formulas are kept. Keep your original.

Why didn’t my file get smaller?

Files that are mostly images or already optimised may not shrink further.

Can I compress XLS files?

Yes, they are saved as modern .xlsx.
